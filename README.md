# MINI HOSPITAL MANAGEMENT SYSTEM

## About the Project
This is a simple Mini Hospital Management System made in Python as a VITyarthi project.
I made this project to practice the Python topics covered in our classes and use them in a small real-life type application. The program mainly deals with basic patient records and some common hospital activities.
The program works through a menu. The user can choose what they want to do, enter the required information, and then return to the main menu.

## What the Program Can Do

The main options in the program are:

Add a new patient
Search for a patient
Display all patient records
Assign a doctor to a patient
Update the consultation status

### Add Patient
The user can enter the details of a patient and add them to the current records.

### Search Patient
A patient can be searched using the patient ID. If the ID is available, the patient's information is shown.

### Display Patients
This option displays the patients that have been added to the system.

### Assign Doctor
A doctor can be assigned to a particular patient.

### Consultation Status
The consultation status of a patient can be changed when required.

## How to Run the Project

1. Install Python
Make sure Python 3 is installed on the computer.
2. Open the Project
Open the project folder in VS Code or any Python editor.
3. Run the Program
Open the terminal inside the project folder and use:
```python main.py```

The main menu will then appear.

How to Use It
After running the program, select an option from the menu.
For example:
- Select Add Patient and enter the required details.
- Use Search Patient to find a particular patient.
- Use Display Patients to see the stored records.
- Use Assign Doctor to assign a doctor.
- Update the consultation status when needed.
Select Exit when finished.
